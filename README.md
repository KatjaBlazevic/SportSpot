# SportSpot

# Pokretanje aplikacije

Projekt se sastoji od dva dijela: **Backend** (poslužitelj) i **Frontend** (klijent). Za pokretanje cijelog sustava potrebno je otvoriti dva zasebna terminala.

---

### Backend

```bash
cd backend
npm install
npm run dev

```

Napomena server runa na portu 5000 ili postavljenom u .env datoteci koju treba nap u backend mapi

### Frontend

```bash
cd frontend
npm install
npm run dev

```
